# 🔄 SOP 02: Tri-Tier Analogy Generation Engine

## 1. Purpose
Wire abstract, domain-specific concepts directly into neural memory and human intuition using three distinct analogies ranked by cognitive depth: Easy, Medium, and Hard.

## 2. The Tri-Tier Hierarchy

### Tier 1: Easy (Intuitive / Organic / Daily Life)
- **Target Audience:** Absolute beginners, cross-functional stakeholders, or engineers needing an immediate mental anchor.
- **Paradigm Examples:**
  - QA Engineer -> The Personal Doctor / Preventative Physician (Routine checkups = regression tests; symptom complaints = bug reports; diagnostic tests = test cases; triage = bug severity prioritization).
  - Cybersecurity -> Castle Defense & Moat Architecture.
  - SRE -> Emergency Room Trauma Ward & Vital Signs Monitoring.
- **Rule:** Must evoke visceral, sensory understanding without technical jargon.

### Tier 2: Medium (Systemic / Multi-Variable / Operational Flow)
- **Target Audience:** Intermediate practitioners, team leads, or engineers coordinating multi-variable systems.
- **Paradigm Examples:**
  - QA Engineer -> Airport Air Traffic Control & Safety Oversight Board (Runway clearance = release gates; radar transponders = automated CI pipelines; bird-strike emergency drills = chaos engineering).
  - DevOps -> High-speed Formula 1 Pit Crew & Telemetry.
- **Rule:** Captures interdependencies, concurrent workflows, and systemic governance.

### Tier 3: Hard (First-Principles / Epistemological / Philosophical)
- **Target Audience:** Senior architects, innovators, and leaders seeking supreme mastery.
- **Paradigm Examples:**
  - QA Engineer -> Karl Popper's Scientific Falsificationism (A system can never be proven bug-free; a test is a deliberate, falsifying experiment designed to shatter unwarranted confidence).
  - Product Management -> Evolutionary Biology & Fitness Landscapes.
  - Data Engineering -> Hydrological Aqueduct Networks & Thermodynamic Entropy.
- **Rule:** Anchors the domain in first-principles epistemology, game theory, or natural laws.

## 3. Structural Mapping Table
Every generated analogy MUST provide a 1-to-1 cognitive mapping table:
- Domain Concept <--> Analogy Counterpart <--> Intuitive Lesson.
