## 2. Technical Stack Considerations
- **Backend:** Python 3.9+ with Flask. Zero complicated build chains, fast boot time (< 1s), lightweight footprint.
- **Local LLM Support:** Optional integration with Ollama (`localhost:11434`) using `llama3.2`, `codellama`, or user models.
- **Deterministic Compiler:** Essential for 100% reliable offline generation. Uses structured domain knowledge templates that assemble every section with rich, tailored content matching the user's domain and experience level.
- **Frontend:** Single-page responsive interface with pure CSS/vanilla JS or Tailwind CDN and marked.js for instant live preview and zero-latency rendering.
